# project-mind-mcp

mcp-name: io.github.usman8786/project-mind-mcp

**Fast code intelligence engine for AI coding agents.** Indexes an average repository in milliseconds, the Linux kernel (28M LOC) in 3 minutes. Answers structural queries in under 1ms.

This package installs the `project-mind-mcp` binary from [GitHub Releases](https://github.com/usman8786/project-mind-mcp/releases). The binary is downloaded on first run and cached in your OS cache directory.

## Installation

```bash
pip install project-mind-mcp
# or
pipx install project-mind-mcp
```

## Usage

```bash
project-mind-mcp install   # configure your coding agents
project-mind-mcp --help
```

## Supported platforms

| OS      | Architecture |
|---------|-------------|
| macOS   | arm64, amd64 |
| Linux   | arm64, amd64 |
| Windows | amd64 |
